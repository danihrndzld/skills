# Testing

- [art-of-unit-testing](./art-of-unit-testing/SKILL.md): few unit tests with high signal, in any language.
- [art-of-integration-testing](./art-of-integration-testing/SKILL.md): controllers, services and API endpoints against real managed dependencies.
- [art-of-e2e-testing](./art-of-e2e-testing/SKILL.md): the few user journeys with the most risk, kept stable.
- [art-of-cicd](./art-of-cicd/SKILL.md): pipelines, quality gates, flaky tests, suite speed and delivery.

Each skill has a copy of `scripts/build_report.py` and a `references/report.md` that explains the report for that level.
